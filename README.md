# BookNest – Library Management System

## Project Description
BookNest is a Library Management System developed to manage library books, users, and borrowing and returning transactions.

## Technologies Used
- React
- JavaScript
- CSS
- Node.js
- Express.js
- MySQL
- REST API

## Project Structure
- `frontend/` – React application
- `backend/` – Express server and API routes

## Installation and Setup

### Backend
1. Open a terminal in the backend folder.
2. Run `npm install`.
3. Configure your database credentials in a `.env` file.
4. Run the backend server using the available start script.

### Frontend
1. Open a terminal in the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.

## Database
The application uses a MySQL database named `booknest_db`.

## Quick Start

1. Start MySQL 8.
2. Import `database/schema.sql`.
3. Copy `backend/.env.example` to `backend/.env`.
4. Enter your local MySQL credentials in `backend/.env`.
5. Run `cd backend && npm install && npm start`.
6. Run `cd frontend && npm install && npm run dev`.
7. Open the frontend URL printed by Vite, normally `http://localhost:5173`.

The API runs at `http://localhost:5000`.
